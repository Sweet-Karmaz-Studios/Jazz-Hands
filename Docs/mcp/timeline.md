# The timeline

`timeline_describe` is the older, shorter cousin of `describe_timeline`: a sequence's tracks and clips as readable text. Prefer `describe_timeline`, which includes the project, media and problems and keeps to a token budget.

`timeline_set_magnetic` keeps the primary picture track gapless: removing or shortening a clip there closes up behind it, as in a storyline editor. `clip_storyline_move` moves clips along that track and closes up where they were.
